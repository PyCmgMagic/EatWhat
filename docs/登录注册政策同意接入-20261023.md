# 登录注册政策同意接入

日期：2026-10-23。基于最新 OpenAPI JSON 和 `https://v50to.you/api/auth/consent/policy` 的实际响应完成接入。

## 当前行为

- PC 密码登录、用户名注册、手机验证码登录/注册，以及对应移动端入口，都要求用户主动勾选政策；默认不勾选。手机验证码的发送也须先确认政策。
- 点击《跨站同步授权政策》打开同风格正文弹窗，展示后端返回的用途、接收方、跨境同步范围、排除项、撤回方式及保留说明，支持打开完整正文。打开、关闭正文都不会自动同意。
- 每次提交前重新读取当前政策，按版本、正文地址和文档摘要核对已勾选内容。版本变化会取消勾选并提示重新确认；加载失败或缺少版本/正文时禁用提交，支持重试。
- 用户名注册和手机登录按 DTO 发送 `crossBorderConsent: true`、`consentPolicyVersion`。密码登录 DTO 未声明这两个字段，因此不添加额外字段；后端要求授权时使用其临时 `consentProof` 进入独立授权页。
- 待授权页再次明确确认，提交 `proof` 和当前 `policyVersion`。proof 请求不带旧会话；proof 仅保存在内存中，刷新丢失时引导重新登录。授权成功只表示授权请求成功，不伪造登录会话，仍须正式登录。
- 已登录账号的设置中保留授权状态、重新授权和撤回入口；重新授权同样必须勾选，使用正式会话提交，不带 proof。
- Mock 使用明确标注的本地演示政策，手动登录也须勾选。开发默认自动进入模拟账号的预览方式保留，不会将演示同意用于真实账号。

新增 `/auth/withdraw-consent` 公开密码撤回入口，不要求先同意政策，且不携带已有会话。公开请求返回 401 不会清除其他现有会话；结果展示后端实际授权和清理进度。详见 [剩余接口接入与验证](剩余接口接入与验证-20261023.md)。

## 政策来源与类型

实测当前版本是 `cross-border-preferences-v3`。接口实际响应还包含 OpenAPI 尚未声明的 `notice`，前端以可选响应扩展读取，未修改生成契约，也未扩大请求字段。

后端正文路径是 `/policies/cross-border-preferences-v3.html`，相对于业务网关解析为 `/api/policies/cross-border-preferences-v3.html`；开发代理实际转发到 `https://v50to.you/api/policies/cross-border-preferences-v3.html`。不能直接拼接到域名根目录，根目录路径实测 404。

`VITE_CONSENT_POLICY_URL` 改为可选覆盖项；通常无需配置，优先采用后端提供的正文路径。跨域覆盖地址需要允许浏览器读取正文。

### 正文空白修复

原来使用 sandbox iframe，空白或加载失败时没有反馈。真实正文返回 `X-Frame-Options: SAMEORIGIN`，内嵌展示会受到浏览器及来源限制。现改为打开弹窗后读取 HTML，直接在弹窗内展示正文，避免依赖内嵌页面。正文使用 DOMPurify 白名单清理脚本、事件属性、远程资源和全局样式，保留段落、标题、列表、表格及安全链接。

加入加载提示、15 秒超时、失败重试及独立新页原文链接。HTTP 失败、非 HTML、空内容及政策版本不符均明确提示；关闭时取消尚未完成的请求。正文公开读取不携带应用 token 或浏览器 Cookie，缓存按政策身份及地址隔离，打开和关闭正文仍不会自动勾选同意。
