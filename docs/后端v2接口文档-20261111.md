## 2. 通用协议

### 2.1 响应和错误

除 SSO 回跳外，业务 JSON 统一为 `Result{code,data,msg,timestamp}`；`code=0` 才成功，无业务数据时 `data=null`。业务异常通常仍为 HTTP 200。路由不存在、方法不符、媒体类型不符分别为 HTTP 404/405/415，并使用业务码 `10004/10004/10001`。`@v2:src/main/java/you/v50to/eatwhat/common/Result.java#L7-L37`；`@v2:src/main/java/you/v50to/eatwhat/common/GlobalExceptionHandler.java#L20-L103`

| 代码 | 含义/典型触发 |
| ---: | --- |
| `10001` | 参数非法：JSON 校验、枚举、坐标或业务约束失败 |
| `10002` | 必填参数缺失 |
| `10003` | 频率过高；响应带 `Retry-After` |
| `20001` | 未登录 |
| `20004` | 缺 `verified` 或 `admin` 角色 |
| `20005` | 新注册/手机号自动建号未同意当前政策 |
| `20009` | 政策版本已更新或会话尚未同意当前版本 |
| `30002` | 用户被禁用 |
| `30003/30004/30005` | 用户名已存在/密码错误/验证码错误 |
| `40001/40002/40004` | 操作失败/状态不允许/重复提交 |
| `40009/40010` | 店铺/商圈不存在 |

完整定义：`@v2:src/main/java/you/v50to/eatwhat/common/BizCode.java#L6-L73`。下表的“主要错误”不重复列 `90002/90004` 等基础设施故障。

### 2.2 会话、角色和政策门禁

- Sa-Token：header 名 `satoken`、前缀 `Bearer`；会话最长 30 天，3 天无操作失效；允许多设备，不共享 token，不读 cookie。`@v2:src/main/resources/application.yml#L33-L40`
- `admin` 来自 `users.role=admin`；邮箱或学校认证成功得到 `verified`。管理员不会自动拥有 `verified`。`@v2:src/main/java/you/v50to/eatwhat/account/service/AccountStpInterface.java#L10-L39`
- 有效会话每次请求都复检封禁和政策状态；政策过期只放行 `GET /auth/consent/policy`、`GET /auth/consent`、`POST /auth/consent/grant`、`POST /auth/logout`。`@v2:src/main/java/you/v50to/eatwhat/account/config/AccountStatusInterceptor.java#L14-L45`；`@v2:src/main/java/you/v50to/eatwhat/account/controller/ConsentController.java#L32-L53`；`@v2:src/main/java/you/v50to/eatwhat/account/controller/AuthController.java#L54-L59`
- 登录/注册兼容 `userName` 与 `username`，并存必须相同；`device` 仅 `WEB|APP`。`@v2:src/main/java/you/v50to/eatwhat/account/dto/AuthDtos.java#L9-L35`

### 2.3 分页和时间

- 普通分页：`page` 从 1 开始；`pageSize<1` 用默认值，超上限会夹紧；响应 `{currentPage,items,totalPages,totalItems,hasNext}`。多数列表默认 20/最大 100，推荐默认 10/最大 30。`@v2:src/main/java/you/v50to/eatwhat/common/PageResult.java#L6-L27`；`@v2:src/main/java/you/v50to/eatwhat/recommend/controller/RecommendController.java#L35-L48`
- 设备会话使用 UUID `cursor` 和 `size`（默认 20，1–100），返回 `{devices,nextCursor}`；设备时间为 ISO-8601 offset datetime。`@v2:src/main/java/you/v50to/eatwhat/account/controller/DeviceSessionController.java#L29-L35`；`@v2:src/main/java/you/v50to/eatwhat/account/dto/DeviceSessionDtos.java#L7-L14`
- 其他 DTO 的时间通常是 Unix 毫秒。`@v2:src/main/java/you/v50to/eatwhat/account/dto/AdminDtos.java#L5-L22`；`@v2:src/main/java/you/v50to/eatwhat/user/dto/UserDtos.java#L3-L28`

## 5. 前端联调专题

### 5.1 认证、重新同意与会话

1. 启动时读取 `GET /auth/consent/policy`。有已发布版本时，用户名注册和所有手机号登录都提交该 `policyVersion`；手机号验证码在政策校验通过后才会消费。缺版本为 `20005`，旧版本为 `20009`。`@v2:src/main/java/you/v50to/eatwhat/account/service/ConsentService.java#L91-L100`；`PhoneAuthService.java#L43-L45`
2. 密码登录可选提交 `policyVersion` 并记录同意。有效会话在普通接口收到 `20009` 时不要清 token：依次取 policy、取 consent status、展示正文、grant，再重试原请求。拦截器只允许四个豁免接口。`@v2:src/main/java/you/v50to/eatwhat/account/service/AuthService.java#L89-L109`；`AccountStatusInterceptor.java#L27-L42`
3. 密码登录累计失败会先给统一 `30004`，达到阈值后给 `30015`；前端弹腾讯验证码并带两头重试。短信、邮件相关发送接口则每次都要求这两个头。`@v2:src/main/java/you/v50to/eatwhat/account/controller/AuthController.java#L44-L51`；`ContactController.java#L44-L49`；`VerificationController.java#L48-L55`
4. token 只放 header，不读 cookie。设备撤销使用派生 UUID，不向前端暴露真实 token；重设密码、改手机号、首次设密码等会下线其他设备。`@v2:src/main/resources/application.yml#L33-L40`；`DeviceSessionService.java#L17-L30`；`AccountSecurityService.java#L148-L180`

### 5.2 上传完整流程

1. 调 `presign` 或 `presign/batch`；签名有效期配置为 300 秒。`@v2:src/main/resources/application.yml#L66-L78`

### 5.4 学校 SSO 回跳
