# 真实地图接入

桌面、平板和手机的附近页已替换原先的 SVG 示意地图与固定位置标记，使用百度地图官方 JSAPI 4.0。SDK 通过官方 `@baidumap/jsapi-loader` 按需加载，类型使用官方 `@baidumap/jsapi-v4-types`；首页不加载地图 SDK。

## 已实现

- 街道底图、拖动、缩放、比例尺与可见的版权署名。
- 依据餐厅接口返回的坐标绘制标记，标记和列表双向选择。没有有效坐标的店铺保留在列表中，不虚构地图位置。
- 默认使用所选区域或校区接口的中心；不把默认中心标记为用户实时位置。只有点击“我的位置”才请求浏览器定位，拒绝后显示提示。
- 桌面和手机新店表单支持地图点击选点、拖动调整标记，坐标回填到表单；区域中心不会自动作为店铺地址提交。
- 底图失败保留店铺列表，支持重试。底图请求不携带应用会话令牌。
- 地图实例在页面间复用，支持同时显示多个独立地图。离页时停止动画、清理页面监听和覆盖物、移除比例尺并暂停自动尺寸检测，避免 SDK 延迟加载的控件或版权信息回调访问已销毁的地图状态。

## 坐标

后端区域、餐厅和新店接口使用 GCJ02。地图与兼容渲染器统一使用百度原生 BD09，在组件边界集中转换：店铺和设备坐标 GCJ02 → BD09；点击、拖动事件 BD09 → GCJ02。浏览器定位的原始 WGS84 坐标先通过现有 `wgsToGcj` 转换。转换与空值校验集中在 `frontend/src/features/map-geometry.ts`，外部导航 URI 显式指定 `coord_type=gcj02`。正向变换已与百度官方 Convertor 服务对照验证。百度坐标类型说明见 [官方文档](https://lbs.baidu.com/docs/jsapi?title=jsapi4/guide/concept/coord)。

## 配置

在被 Git 忽略的 `frontend/.env.local` 中配置浏览器端 AK：

```dotenv
VITE_BAIDU_MAP_AK=你的浏览器端AK
```

在百度地图开放平台开启 JavaScript API 服务，并为本地及部署域名设置匹配的 Referer 白名单。真实 AK 不写入示例文件或版本库。部署新环境时同样需要该环境变量。

保留百度地图原生版权和审图信息，不直接拼接商业瓦片地址。SDK 失败、超时或配置缺失时保留店铺列表与重试入口，不回退为假地图或另一服务商。SDK 错误会过滤原始脚本地址，避免把 AK 显示在错误提示中。加载方式依据 [百度官方文档](https://lbs.baidu.com/docs/jsapi?title=jsapi4/guide/concepts/load)。

```powershell
Set-Location ..
npx --yes --package @playwright/cli playwright-cli -s=eatwhat-profile-fix open "http://127.0.0.1:5173/#/nearby"
npx --yes --package @playwright/cli playwright-cli -s=eatwhat-profile-fix --raw run-code --filename frontend/scripts/real-map-flows.js

```

浏览器脚本拦截业务接口写入，加载真实百度 SDK 与底图；覆盖手机、平板、桌面、标记与列表选择、定位与坐标转换、底图失败重试及新店选点。脚本不创建远程餐厅、不使用真实用户登录凭据。结果在 `output/baidu-map-browser-validation.log`，截图在 `output/playwright/baidu-map-*.png`。
