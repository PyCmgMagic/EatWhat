## 环境配置依赖

当前本地开发默认使用 Mock，首次打开自动登录模拟学生。登录欢迎页和密码页均可「一键 Mock 登录」，无需真实凭据；主动退出后刷新仍保持退出状态。Mock 会话和本地业务数据与真实接口隔离，开发地址加 `?demo=0` 可恢复真实联调。生产包默认关闭 Mock。

1. 可访问的测试网关与允许的前端 Origin。默认开发启动不自动指向文档中的远程主机。
2. 可用于普通、未认证、已认证、管理员、封禁场景的测试账号；管理员不默认继承 verified。
3. 图片存储 key 的永久读取前缀，和允许原始 PUT 的存储 CORS 配置。
4. 与 `/auth/consent/policy` 当前版本对应的完整政策正文地址；未配置时不允许同意提交。
5. 能保持当前自定义头会话的统一认证入口与回调约定。当前不把 token 放入 URL。
6. 后端角色、业务错误码、时间字段、金额单位、int64 ID 表示的实际响应样例。

配置说明见 `frontend/.env.example` 和 `frontend/README.md`。
