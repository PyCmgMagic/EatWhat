# 移动端原型还原与实现

更新：2026-10-22。当前视觉唯一基准为本地 `prototype/`，接口唯一基准为 `docs/吃什么接口文档v2-openapi.yaml`。原型名称中出现“沙软”，项目继续使用用户确定的“山软今天吃什么”。

## 还原方式

先读取原始 HTML、设计规范、tokens 和资源，再将 51 张画板编译为本地 React 页面。保留源 CSS 数值、内联 SVG、菜品插画、MingCute 图标和原始控制器的转盘/切换动效。中文 Noto Sans SC、数字 Bricolage Grotesque 均本地托管；不加载缺失的 support.js，不依赖 Claude Design 在线运行环境，不使用 iframe 或运行时 eval。

基准尺寸 390 × 844；520px 舞台、488px 抽屉起点、28px 圆角、20px 页面边距、60px 三栏导航和独立发布圆钮沿用来源。窄屏按比例缩放，主页面在短屏中调整抽屉可视高度和导航位置；桌面居中显示移动画布，组件规范等宽画板可横向查看。

`/?demo=1#/design` 列出全部画板；`/#/reference/<画板名>` 保留原始样例，便于对照。业务路由通过 `src/mobile/bridge.tsx` 绑定接口、权限和状态，样例不能作为真实模式的成功响应。

## 与接口有关的明确边界

- 推荐仅支持 limit，分类只筛选当前组；饭点选择是界面偏好，不能声称触发后端按饭点筛选。全站菜品关键词搜索待补充。
- 收藏分类只筛选当前页，不能声称已经查询全量分类收藏。
- 菜品/餐厅创建返回 Void，成功后进入我的或列表。初始标签保留为草稿意图，提示找到准确新菜后再保存，绝不推测 ID 或写到同名菜上。
- 照片裁剪和取色真实在客户端完成。自动去背景待接入；色值只在本机保存，后端暂无色值同步字段。草稿不跨刷新持久化。
- 原型的数字和身份示例在业务页面改为接口字段；未知距离、价格、设备状态等不能由样例冒充。设计对照页仍保留原始样例。
- 评论、举报、反馈、纠错、设备列表/下线、屏蔽、账号注销、手机号验证码注册、换绑和匿名找回密码没有完整协议，保留视觉并标注待接入，操作不伪造提交成功。
- 地图坐标图层、餐厅口味聚合、通知偏好、个性化开关和专题目录仍需服务端/地图配置。可用列表与附近示意底图分开说明。
- 手机注册不是现有用户名注册接口的替代协议。现有手机绑定仅用于已登录且未绑定场景；认证会话、授权政策全文与回调仍需部署方配置。

## 工程与维护

`frontend/scripts/compile-prototype.py` → `src/mobile/generated/{trees.json,controllers.tsx,tokens.css,manifest.json}`；资源复制到 `public/prototype/assets/`。运行 `npm run prototype:generate` 可重建。业务扩展在 renderer、bridge、ui、photos、catalog、routes、App 和 mobile.css 中。

生成文件不手改。结构节点编号来自源画板，因此更新 HTML 结构后必须检查 bridge 绑定。原型源文件保持原样，旧界面仍留在仓库中供历史参考。
