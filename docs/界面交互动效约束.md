# 界面交互动效约束

适用于 `frontend/` 的手机、平板、桌面和管理后台。已有本地设计规范继续约束页面布局、颜色、字体和资源；有明确点击入口的临时浮层按本文实现。历史原型中的统一底部面板约定，在评分、补价和轻量确认场景中以本文为准。

## 适用场景

| 场景                                   | 交互与组件                                                                         |
| -------------------------------------- | ---------------------------------------------------------------------------------- |
| 筛选、排序、表单单选                   | 使用共享 `Select`，保留原生表单值、校验、标签和键盘选择能力                        |
| 菜品、店铺、食友及账户操作菜单         | 使用 `ActionMenu` 或 `AnchoredPopover`，从触发侧展开，靠近视口边缘时翻转或调整位置 |
| 评论表情、搜索建议                     | 复用 `AnchoredPopover` 或 `AnimatedSurface`，沿用入口位置及搜索框已有的形变        |
| 评分、补充价格、隐私确认、设备下线确认 | 使用 `Modal` 的 `motionOrigin`，从触发控件的实际矩形展开成浮动卡片，关闭时收回入口 |

完整表单、长内容、页面导航和底部抽屉沿用对应的布局与动效。缺少有效来源元素时，使用共享组件的常规打开方式。

## 形变与节奏

- 外壳从入口或锚定侧展开。弹出后的位置由可用空间和内容尺寸决定，不将触发控件的尺寸当作最终卡片尺寸。
- 外壳变化与内容分层；反向缩放抵消外层缩放，使文字、图标、星星和输入控件保持原尺寸。背景与内容的透明度分别过渡，内容随容器整体呈现。
- 展开迅速启动并柔和落定，关闭更短。容器已经形变时，子项保持同步，不再叠加入场位移或逐项延迟。
- 几何展开使用 `cubic-bezier(0.105, 0.908, 0.193, 0.964)`，回收使用 `cubic-bezier(0.4, 0, 1, 1)`；共享控制器单独处理背景与内容透明度。

下表是当前常规速度的参数；调整时在共享控制器或组件参数中统一修改，并同步本文。

| 场景                     | 展开  | 回收  |
| ------------------------ | ----- | ----- |
| 常规筛选、排序 `Select`  | 340ms | 120ms |
| 高频表单内 `Select`      | 200ms | 100ms |
| 操作菜单、账户菜单       | 260ms | 120ms |
| 紧凑食友菜单             | 220ms | 120ms |
| 评论表情、搜索建议浮层   | 180ms | 100ms |
| 从入口展开的轻量 `Modal` | 340ms | 180ms |

## 生命周期与可访问性

- 使用当前可见状态作为反向动画的起点；中途关闭或快速重开时连续过渡，取消旧动画及其过期回调。
- 关闭时先使浮层不可交互，保留节点和顶层状态至回收完成，再移除并将焦点还给入口。关闭按钮、取消、点击遮罩共用 dismiss；自定义取消按钮通过 `Modal` 的 children 回调取得 dismiss。业务提交成功后的关闭由业务状态决定。
- 模态对话框保留原生 `dialog.showModal()`、遮罩、焦点限制和页面滚动锁定。菜单和选择器保留对应的角色、可访问名称、展开状态、选中状态及键盘操作。
- 键盘触发和系统「减少动态效果」即时完成状态切换，焦点和操作反馈正常生效。
- 定位使用实际入口矩形，并处理 CSS `zoom`、滚动、窗口变化与视口边界。内容过长时在卡片内滚动，保留关闭入口。
- 动画优先使用 `transform` 和 `opacity`，临时设置 `will-change` 并在结束或取消时清理。保持深浅色主题下的背景、文字、遮罩及控件可读性。

## 验收

修改涉及这些浮层时，通过正常入口检查以下行为，并运行受影响组件的现有测试与类型检查：

1. 正常打开和关闭能看清入口与卡片的空间关系；慢放时文字及图标保持原尺寸。
2. 展开中关闭、回收中重开均无跳变、闪烁、重复浮层或过期回调。
3. 关闭按钮、取消和遮罩均完成回收；键盘操作即时响应，退出后焦点返回入口。
4. 原有选择、搜索、评分保存、错误反馈和提交结果正常；动画期间重复点击不会触发重复业务操作。
5. 手机和桌面布局、视口边缘、滚动及缩放下无裁切或横向溢出；深浅色与减少动态效果路径正常。
6. 动画完成或取消后，移除节点、滚动锁定和 `will-change` 均按状态清理。共享控制器变更时回归菜单、选择器和轻量对话框。
