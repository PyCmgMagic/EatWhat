# 代码审查修复与验证（2026-11-09）

本次修复审查确认的 7 个问题，并将原先的隔离复现加入常规回归测试。

| 问题 | 修复后的行为 |
| --- | --- |
| 资料回读与退出登录竞争 | 回读失败的兜底先检查操作所属会话，取消请求不写回旧资料；新登录移除旧身份缓存并重新查询身份。 |
| HTTP 200 携带登录失效业务码 | 与 HTTP 401 统一清理当前失效会话；公开登录请求失败和旧会话的晚到响应不会清除新账号。 |
| 移动发布防重随页面卸载丢失 | 提交中和创建结果未知状态保留在共享草稿，重新进入编辑器继续禁止重复创建，并显示核实提示。 |
| 会话失效删除恢复凭据 | 自然失效保留当前标签页中的待恢复命令；主动退出、新登录和外部账号切换继续清理旧命令。凭据不自动持久化。 |
| 审核图片混入其他提交 | 图片组件按修订和权限模式隔离；切换即清空，旧请求晚到也不会插入新提交。 |
| 手机号准备请求被拒绝后无法重试 | 明确失败撤销命令状态、保留号码供修改；结果未知继续保留凭据供查询恢复。 |
| 反馈允许超过后端上限 | 意见反馈的输入、字数提示和提交校验统一为 500 字，校验先于截图上传。 |
