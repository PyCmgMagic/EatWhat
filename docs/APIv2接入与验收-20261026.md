## 迁移与功能

- 登录、注册、查重及密码撤回使用 `userName`；展示昵称与编辑资料使用 `displayName`。手机账号没有登录名时仍能展示昵称，昵称使用 2–12 字符规则。
- 政策读取使用 `version/url`。站内绝对路径不会重复拼接 `/api`；正文净化并核对版本，加载失败不能提交同意，版本或地址变化后重新确认。取消旧前端正文覆盖配置，以服务端政策为准。
- 推荐读取 `data.items`，保留首页切换及换一组；普通菜品与推荐共用展示模型，兼容推荐专属字段为空。重复菜品错误 `40016` 保留已有菜品编号，提供查看入口并保留输入。
- Mock 迁移保留已上传的菜品、照片、资料与历史；旧昵称不推断为唯一登录名。推荐、普通菜品、授权状态等返回结构同步迁移。

| 功能 | 页面与行为 |
| --- | --- |
| 首次设置登录名 | `/settings/username`；手机新账号登录后可跳过引导，账号安全中可再次进入。支持初始密码；保存成功后清理会话、授权凭证及私有缓存，重新登录并预填新登录名 |
| TA 的分享 | `/users/:id`；手机、平板与 PC 均显示真实分享，支持关键词、分类、排序和分页，互动状态属于当前访问者 |
| 足迹清空 | `/history`；支持当前分类或全部，确认后更新所有相关分页缓存，重新从第一页读取 |
| 个性化推荐 | `/settings/privacy`；读取实际开关状态，保存失败恢复已确认状态，不删除口味与历史 |
| 屏蔽 | 食友主页及 `/settings/blocked`；查询、屏蔽、解除、分页列表与推荐缓存更新；接口未部署时显示暂不可用并允许重试 |
| 密码冲突恢复 | `/auth/forgot` 与 `/auth/password-conflict/reset`；申请恢复邮件、手动输入或读取链接令牌，读取后清除 URL 中的令牌，不持久化密码或令牌 |
| 政策管理 | 后台“授权政策”；维护版本与正文地址，使用 `expectedRevision`；冲突保留输入，不自动覆盖重试，重新读取后比较再保存 |
| 账号安全复核 | 后台“账号安全复核”按事件 UUID 批准或驳回；用户管理按明确的数字用户 ID 重置密码冲突 |
| 资料冲突 | 后台展示候选 ID、内容与版本向量；读取模型 `{id,value,vector}` 无法安全转换为旧裁决 DTO，因此不开放提交表单 |

另修复了确认弹窗退出与懒加载页面切换时，内容偶发残留不可交互状态的问题；弹窗打开时背景仍被锁定，关闭后恢复操作。

## 人机验证

统一覆盖六类发送：手机登录短信、密码短信、绑定手机短信、学校认证邮件、旧短信入口、密码冲突恢复邮件。

SDK 仅在发送操作时加载；每次验证匿名读取新的 `no-store` 配置并新建实例。成功回调的 `ticket/randstr` 通过两个 `X-Captcha-*` 请求头提交；取消、错误、过期、重复回调、页面卸载及业务失败均丢弃本次材料。禁止自动重发或复用票据，仅业务发送成功后显示成功并启动倒计时。

Mock 使用独立模拟弹层，支持取消、失败与成功，不加载腾讯 SDK，不请求真实发送服务。点击“完成验证”后，演示短信验证码为 `123456`；恢复邮件的演示令牌为 `demo-recovery-token`，保存在本次运行内存中。

## 真实服务与待联调项

- baseURL 保持 `https://v50to.you/api`。已只读验证当前政策接口及正文返回成功，且经本地同源代理读取正文正常。
- 从 `http://127.0.0.1:5173` 直接跨域到短信接口的 OPTIONS 预检返回 403，未返回允许源或请求头。当前开发使用同源 `/api` 代理；生产也可配置同源网关。若采用跨域部署，需要后端针对实际前端域名允许相应方法、会话头及两个 `X-Captcha-*` 头。
- 腾讯真实人工挑战、短信/邮件实际投递、学校统一认证与真实账号安全流程仍需在授权测试账号下联调，本轮未自动触发。
- 屏蔽及多写账号恢复等能力受后端部署、开关和权限控制；前端明确显示不可用状态。资料冲突裁决需后端提供一致的读取与提交契约后开放。
