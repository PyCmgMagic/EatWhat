## 1. 现状诊断：旧原型与最新后端 v2 的体验错位

旧版原型（2026-10-22「舞台转盘」方案）基于早期“单菜推荐 + 个人自定义标签 + 审核发布”的契约设计；而最新后端 v2（2026-11-18 / V30）已经演进为**以店铺为推荐单位、菜品为口碑与外卖载体、开放 Wiki 式共创**的完整产品模型。直接沿用旧交互会带来 5 处明显体验断层：

1. **决策单位错位**：旧首页是单道菜大转盘，但同学饭点真实决策顺序是「先选堂食还是外卖 → 再定去哪家店 → 最后看店里哪 1–3 道菜最好吃」，后端 `/recommend` 与 `/recommend/pick` 也已明确以店铺为主体并附带最多 3 道 `signatureFoods`（按评分自动选出的代表菜）。
2. **堂食与外卖混为一谈**：后端已将外卖开关下沉到菜品（V24），且堂食看距离+堂食口碑、外卖不看距离+要求当前饭点有可外卖菜品。旧交互缺少首屏级「堂食 / 外卖」切换，容易把不可外卖的店推给宿舍点餐用户。
3. **高价值新能力缺乏显性入口**：
   - `POST /recommend/dismiss/{id}`（30天内不想吃）被埋藏，用户无法及时纠正不喜欢的店；
   - `kind=buffet`（自助餐，V30）与 8 大山大校区 GCJ-02 位置预设（V26/V27）未体现在首页架构中；
   - 显式偏好（尤其是硬忌口 `辣/麻`）、隐式口味（`/user/recommendation-profile/taste`）与合规的个性化开关（`/user/recommendation-settings`）隐藏过深；
   - `POST /foods/suggest-tags`（AI 识图填分类和口味）、上传前查重（`/foods/duplicates`、`/restaurant/duplicates`）、开放共创修订历史（`/history` + 一键恢复）未形成顺滑闭环。
4. **互动语义容易混淆**：v2 非常清晰地划分了三种反馈——店铺「堂食/外卖 推荐 vs 不推荐（并记入“吃过了”防 7 天复推）」、菜品「♥ 想吃/点赞（没吃过也能点）」、菜品「★ 1–5 吃过打分（吃过后评）」。界面文案和布局必须把这三者彻底拉开，避免误解。
5. **已废弃能力的包袱**：个人自定义标签（`/foods/tags/my`）、内容审核队列（`/moderation/*`）、跨站同步、专题活动在 v2 均已取消或暂缓；而评论、楼中楼回复、食友晒图墙、Lv.1–Lv.10 等级与「老吃家」称号已正式落地。

## 2. 以用户体验为核心的 6 项重构设计

### 2.1 首屏双模式决策舱：「摇一摇决策卡 + 推荐口碑流」
- **顶部一行定基调**：`📍 校区坐标预设 · 自动饭点`（点击弹 8 校区 + 4 饭点面板）+ `堂食 / 外卖` 一键主切换 + `正餐美食 / 甜点饮品 / 自助餐` 业态切换。
- **单店快速决策卡（对应 `GET /recommend/pick`）**：展示店图、对应场景推荐率、人均价位档、商圈/距离，以及最多 3 道**当前饭点与场景可用的高分代表菜**（点击直达菜品）。底部给出明确的 3 个高频动作：
  - **不想吃（30天不推）**：调用 `POST /recommend/dismiss/{id}`，并弹出带「撤销」的轻量 Toast；
  - **换一家**：带轻动效刷新下一家；
  - **就去这家 / 看菜单**：直达店铺详情。
- **下方推荐流（对应 `GET /recommend`）**：不再只展示单图，每张店铺卡同步露出「堂食/外卖推荐率」与「代表菜快捷胶囊」，兼顾“懒得想直接抽签”和“想逛逛对比几家”两类心智。

### 2.2 口味与忌口雷达前置 + 算法透明可控
- 在首页次级操作区放置**「口味与忌口」状态胶囊**（实时回显如 `忌辣`、`≤2km` 或 `个性化开/通用排序`）。
- 抽屉面板将三件事合而为一：
  1. **硬忌口（辣 / 麻）与预算、堂食距离滑杆**（实时生效）；
  2. **系统猜你喜欢（隐式口味透明卡）**：读取 `GET /user/recommendation-profile/taste`，清楚告知学生“基于你的点赞、收藏与店铺评价推断，**绝不使用浏览足迹**”；
  3. **个性化推荐开关**：读取/写入 `GET/PUT /user/recommendation-settings`，关闭后即刻切为游客同序且保留历史数据。

### 2.3 搜店与按菜名找店一体化
- 统一搜索框支持搜店名、商圈、地址与**菜名**（对齐 `GET /restaurant/search` 的 `matchedFood` 能力）。
- 当通过菜名命中一家店时，店铺卡片底部直接展开**「命中菜品高亮条（菜名 + 价格 + 直达按钮）」**，解决“我就想吃炸蛋螺蛳粉，告诉我哪家有”的核心诉求。
- 顶部提供高频一键滤镜：**口碑好店（≥70% 且 ≥3评）**、**支持外卖**、**价位档**，并与 GCJ-02 地图标记双向联动。

### 2.4 店铺与菜品详情：清晰的“两层评价 + Wiki 共创”
- **店铺详情**：
  - 并排展示 **堂食口碑** 与 **外卖口碑** 双卡片，点击「👍 推荐 / 👎 不推」即时反馈，并温和提示“已记入吃过记录，近 7 天减少重复推荐（+3 经验）”；
  - 提供 **「共建历史 / 完善店铺」** 入口，展示所有认证同学的公开修订记录与「一键恢复版本」，建立社区共创信任感；
  - 菜单默认展示本店**全部菜品**，并清晰标注每道菜的供应饭点（如 `仅早餐` / `全天供应`）与 `可外卖` 标识。
- **菜品详情**：
  - 区分 **「吃过打分 ★1–5」** 与 **「♥ 想吃点赞」**、**「收藏」**；
  - 展示 **食友晒图墙（`GET /foods/{id}/gallery`）** 与 **发布即公开的实时评论 + 一层回复**，作者旁展示 `Lv.X` 及满级 `老吃家` 称号。

### 2.5 30 秒智能发布工作流
- **先选店、后选图、再填名**：输入菜名时实时调用 `GET /foods/duplicates` 做**柔和查重提示**（不粗暴阻断，直接引导去完善原词条）；
- **✨ AI 识图填分类与口味**：调用 `POST /foods/suggest-tags`，一键填充菜品分类与口味标签，同时提示“仅作建议，可按需修改”；
- **菜品级供应设置**：饭点默认选中 **「沿用店铺」**（零心智负担），需要限定早/夜宵再多选；独立提供「支持外卖」开关；
- **即时正反馈**：发布即公开，通过 Toast 展示 `+15 经验` 与距离下一等级的进度。

### 2.6 我的与成长档案精简聚焦
- 移除了已下线的个人标签体系，重构为 **收藏店铺 / 收藏菜品 / 30天私密足迹** 三个清爽分区（足迹页显式注明“仅自己可见，不用于推荐”）；
- 个人头图集成 **SDU 认证标识、Lv.1–Lv.10 经验进度条、Lv.10「老吃家」预告、获赞/粉丝/关注**；
- 聚合通知卡片支持按日期分组、未读红点与一键全部已读（含新设备登录提醒等系统消息）。
