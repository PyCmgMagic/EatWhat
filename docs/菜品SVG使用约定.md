# 菜品 SVG 使用约定

用户明确喜欢现有菜品插画。后续新增界面优先复用这组素材；需要补图时延续同一画风。

## 首页菜品卡片

2026-11-08 用户确认沿用圆盘展示。正式首页的实拍照片使用圆形遮罩和浅色底，保留圆盘版原型的两列网格、左右错位构图；`G-HomePhoto` 的矩形实拍卡片仅用于原型对照，不作为正式首页的切换目标。

上传时的圆形取景决定菜品主体的位置与大小，展示时沿用该构图。缺图和加载失败继续使用下文规定的带说明 SVG 兜底。若以后修改卡片的图片比例或取景范围，应同步核对上传预览，避免用户确认后的主体被意外裁掉。

## 画风

- 200 × 200 viewBox，俯视餐盘。白瓷盘半径 92，轻微右下投影；青花蓝 `#2F5D9A` 的圆环或点饰。
- 食材用不规则圆润形状和少量内部线条：米白 `#FBF6EA`、汤色 `#EFCB8C`、蛋黄 `#F6CE57`、葱绿 `#5FA34A`、嫩绿 `#A6D07A`。阴影采用低透明度平涂。
- 沿用页面现有字体，插画中不嵌入标题、等级或数字。SVG 自包含，无外部资源、脚本、滤镜或位图。

## 应用

统一通过 `DishIllustration` 使用。原型素材仍在 `frontend/public/prototype/assets/dishes/`；补画素材放入 `frontend/public/assets/dishes/`，避免原型重新生成时覆盖。

2026-11-08 新增蛋炒饭 `danchaofan.svg`、小笼包 `baozi.svg`。应用于成长入口与等级摘要、成长记录空态、浏览足迹空态和帮助反馈卡片；云吞、饺子、杨枝甘露与香锅用于个人总览、收藏店铺、反馈记录和专题空态。

入口中的小餐盘约 48px，摘要 88–112px，空态 100–132px。每个区域以一盘为主，保留正文和操作的空间；不增加持续旋转、跳动或无目的动画。

插画是装饰，设置 `aria-hidden`、空 alt、固定宽高；加载失败保留轻量餐碗兜底。错误状态保留错误含义和重试。

菜品卡片缺少照片时，按用户要求使用 `FoodPhotoFallback`：复用对应分类的插画，降低饱和度，配虚线标注“示意图 · 暂无实拍”。图片加载失败时标注“示意图 · 加载失败”；保留已有签名链接刷新机制，新的图片地址成功后恢复实拍。插画不能无标识地冒充真实菜品，说明文字必须在小屏卡片内完整可见。此兜底用于菜品卡片，不替代店铺照片或用户头像。
