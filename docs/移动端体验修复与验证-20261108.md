# 移动端体验修复与验证（2026-11-08）

本轮以 `prototype/` 移动端画板为基准，修复导航与页面割裂、认证引导、发布图片和标签、可拖动面板等问题。所有修改都在业务适配层和独立组件中，未直接修改生成画板。

## 页面与交互

- 登录、个人中心、账号安全和设置子页统一导航、字体、间距及按钮样式；编辑资料取消或保存后返回进入编辑器的页面。
- 有拖动条的内容面板支持触摸、鼠标和键盘操作。附近页上拉扩大列表，下拉恢复地图；搜索与导航保持可用，列表滚动不拖动整个页面。
- 修复关注与粉丝面板的大块空白、加载骨架宽度偏移、详情内容溢出和图片异常状态。
- 通知偏好显示原型馄饨 SVG、「正在备菜」「敬请期待」和返回发现入口，不挂载尚未开放的推送设置与设备登记控件。

## 认证与返回路径

- `src/api/access.ts` 根据从 APIv5 生成的规则处理登录、学生认证和维护状态；页面写操作共享同一入口。
- 服务端明确报告用户未认证时，统一弹窗引导，不把错误当作成功，也不在认证后自动重放写操作。
- 学生认证页面说明学校统一认证与邮箱认证任选其一；完成态展示认证记录和明确的返回入口。
- 启动时处理服务端固定的 `/home?result=...&code=...` 回调，重新查询账号状态。短期来源记录支持新标签页、刷新和账号一致性检查。

## 发布与上传

- 裁剪窗口、首页缩略预览与导出图像共用取景计算，保留原始图片比例。
- 发布目的地显示所选餐厅名字，选择餐厅、裁剪返回和换店时保持关联。
- 标签输入常驻，支持添加、回车与完成时保存；草稿标签立即显示、可移除，校验重复和长度，失败后保留输入。新菜发布前不向已有菜品写标签。
- 单图与多图共用图片上传处理。失败时不继续确认或发布；重试获取新凭证，保留已确认图片。
- `UPLOAD_PROXY_TARGET` 仅在本地 Vite 开发服务启用固定 R2 桶的签名 PUT 代理，不转发应用会话。生产包不包含开发代理目标。存储配置见 [R2 图片上传与 CORS](R2图片上传与CORS.md)。

## 验证入口

在 `frontend/` 执行 `npm test`、`npm run typecheck`、`npm run api:access:check`、`npm run build`。当前为 42 个测试文件、362 项单元与契约测试。

部署工具依赖 Linux `fcntl`，在 Ubuntu 中执行 `python3 -m unittest discover -s scripts/tests -p test_frontend_deploy.py -v`，19 项测试通过；测试使用临时目录与模拟发布，不操作生产服务器。

浏览器脚本由 Playwright CLI 的 `run-code --filename` 运行，需先启动开发服务器。各脚本使用独立上下文和模拟业务接口；地图脚本允许加载真实百度地图资源。不要把模拟业务测试等同于生产端到端验收。
