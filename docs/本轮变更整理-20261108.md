# 本轮变更整理

日期：2026-11-08。汇总自 `6a3187c` 之后的工作区修改，按用户要求提交并推送到 `main`。本轮包括以下三个部分；此前已提交的移动端导航、认证弹窗、发布与上传修复不重复计入。

## 附近地图与定位

- 首页去掉桌面端重复的地点与饭点入口。
- 进入附近页自动请求定位，使用当前位置查找店铺；拒绝或失败时保留区域选择与重试，切页或手选区域后忽略迟到结果。
- 大圆店铺标记改为小图钉，选中态显示完整店名并与列表联动。
- 密集店铺按屏幕距离聚合；同位置或最大缩放仍重叠时展开选择列表，支持键盘关闭和焦点恢复。
- 店名避让标记、其他店名及地图控件，地图视野为桌面店铺卡片留出空间。

## APIv6 接入

- 类型生成、权限生成、契约测试与覆盖审计统一使用用户提供的 APIv6 JSON，保留原始文档。
- 新增成长页、经验流水分页、管理端活跃统计，以及统一的前台活动上报与限频。
- 设置登录名按返回标记保留会话；旧版要求重新登录时保留新登录名预填，避免权限页覆盖目标跳转。
- 注销默认匿名保留内容，也可明确选择删除；提交后锁定选项，恢复文件保留同一选择。
- 菜品作者优先使用新 `user` 对象，兼容旧返回；显式为空时不生成作者资料链接。
- 学校回调由后端处理，前端核验最终认证状态并保留来源；公开与可选登录接口继续允许游客浏览。

逐项决策、接口分类和验收范围见 [APIv6 接入规划与验收](APIv6接入规划与验收-20261108.md)。

## 菜品插画

- 补画蛋炒饭、小笼包两张轻量 SVG，延续原型的俯视餐盘、青花描边、柔和配色与轻阴影。
- 在成长入口与摘要、经验及足迹空态、个人总览、帮助反馈、收藏店铺和专题空态复用菜品插画。
- 统一装饰语义、固定比例与加载失败兜底；真实照片缺失时不以插画代替。
- 将用户的画风偏好及补图规则写入 [菜品 SVG 使用约定](菜品SVG使用约定.md)。
