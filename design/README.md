# 沙软今天吃什么 · HTML 交互设计稿

入口：[index.html](index.html)；独立手机预览：[mobile.html](mobile.html)。

## 视觉方向

校园饭卡与日常食物带来的轻松感：浅鼠尾草绿画布、深松绿导航、青柠色重点，搭配宋体展示标题和清晰的无衬线正文。推荐采用带虚线与圆形缺口的饭卡；周围保持克制的边线和留白。食物摄影负责传达食欲，不使用不相关的装饰素材。

颜色：画布 `#F6F8F5`、纸白 `#FFFFFF`、文字 `#253C33`、深松绿 `#24483E`、青柠 `#D3EFA4`、浅鼠尾草 `#E8EFE5`。

## 可体验内容

- 发现：分类、搜索、排序、区域选择、菜品卡片。
- 菜品：详情弹窗、餐厅入口、点赞、收藏、个人分类。
- 推荐：饭卡展示、切换候选、打开详情。
- 收藏：分类切换、取消收藏、重命名分类。
- 发布：选择餐厅、本地图片预览或示例图、表单校验、本次预览中的发布结果。
- 我的：个人资料、当前分享、浏览足迹、编辑昵称签名、认证状态演示。
- 通知：本地示例消息与已读操作。
- 手机：响应式布局、底部导航；mobile.html 使用独立 iframe 展示手机宽度。

## 预览方式

直接双击 `index.html` 即可打开；所有食物图片、样式和脚本均在本地，不依赖 CDN 或构建工具。

也可在项目根目录运行：

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory design
```

然后访问 `http://127.0.0.1:4173`。

## 范围与真实接口

这是视觉与交互设计稿，没有连接真实后端。人物、店铺、价格、认证和互动全部为示例，不代表真实校园经营信息。收藏、点赞、分类和昵称可保存在当前浏览器；本地发布只在本次页面会话保留。图片选择只生成本地预览，不上传。

跨餐厅分类和收藏筛选体现 PRD 的目标体验，正式实现仍依赖 `PRD.md` 中的后端增补。普通用户没有编辑/删除共享菜品的入口；账号设置中的认证按钮仅切换设计状态。

食物摄影来自 Unsplash，下载地址见 [assets/sources.json](assets/sources.json)。照片用于示意，不是对应餐厅的实拍。代码绘制的图标、饭卡及品牌标记为本设计稿的组成部分。
