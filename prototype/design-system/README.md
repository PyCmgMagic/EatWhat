舞台是「沙软今天吃什么」的界面规范。每一屏都有一道主角菜，界面的颜色跟着这道菜走；其他东西退到白色抽屉里，安静地排好。

## 页面结构

- 有一道主角菜的页面用「舞台 + 抽屉」：上半屏是舞台（`Stage`），颜色取自这道菜；下半屏是白色抽屉（`Sheet`），从舞台底部往上压 32px。发现、菜品详情、餐厅详情、我的、发布第 2 步都用这个结构。
- 列表和操作类页面用白底：消息、选店、搜索、评论、设置。不要为了好看硬加舞台。白底页面左上角是 44×44 的返回，下面是 `page-title` 大标题；分组靠 13px 的小标题和留白，不加卡片。
- 临时的选择和确认用底部面板（`Panel`）：压在当前页上，背后一层 `scrim`，选完就收起，不跳新页面。地点和饭点、筛选、加标签、举报、退出登录的确认都是面板。
- 附近页把地图当舞台，抽屉同样压在地图上，这时抽屉加 `shadow-sheet`。
- 底部导航只出现在三个主页面（发现、附近、我的），用 `NavBar`，悬浮在内容上方：距左右 `space-16`，距底部 `space-24`。滚动列表的底部要留出约 100px，最后一项不能被导航盖住。
- 页面左右边距统一 `space-20`。

## 内容与语气

- 像同学之间说话：短句，直接说事。「在哪家吃的？」比「请选择餐厅」好。
- 按钮写清楚会发生什么，同一个动作全程同一个叫法：「就它了」「换一个」「加一道菜」「发布」。流程里的下一步可以带上对象：「下一步：给袁记云饺加菜」。
- 不用中点「·」把几条信息串成一行。店名、距离、商圈分成两行，或用间距隔开。
- 距离写「320 m」，数字和单位之间有一个空格；价格写「¥18」，整数不写 .00；时间写「12 分钟前」「周一」「10 月 18 日」。
- 专题名、标签名用「」引用：收进了本周专题「期末续命餐」、加了标签「皮薄」。
- 不用 emoji，不用感叹号堆情绪。空状态说清楚下一步做什么。
- 没有接口的功能照样画出来，旁边放「待接入」虚线小标（见 `Chip`），接口上线后直接换成真实内容。

## 颜色

- 没有品牌主色。主操作用 `ink` 实心，次操作用 `mist` 或描边。颜色的个性全部来自舞台色。
- 舞台只能用 9 个 `stage-*` 颜色。浅色舞台（`stage-broth` `stage-mango` `stage-bamboo` `stage-chili` `stage-porcelain` `stage-matcha`）上文字用 `ink`；深色舞台（`stage-tomato` `stage-redoil` `stage-soy`）上文字用 `paper`。每个颜色的深浅是写死的，不在运行时去猜。
- 舞台上的按钮跟着舞台走：实心按钮的底色用舞台文字色、文字用舞台色；次按钮用 `stage-ghost-light` / `stage-ghost-dark`。
- 白底页面只用 `ink`、`ink-muted`、`mist`、`hairline`。`warn` 只用来提示用户该做什么，而且一定配文字。
- `map-*` 和 `crop-*` 只在地图和调整照片页里使用。

## 字体

- 中文统一 Noto Sans SC（iOS 上可以回落到苹方）。字重 900 做主角：菜名 `stage-dish`、页面标题 `page-title`、分区标题 `section-title`。
- 数字只用 Bricolage Grotesque：价格 `price-hero` / `price-inline`、统计 `stat`、距离 `distance`、计数 `count`。中文永远不用它。
- 选中状态靠字重，不靠颜色：分类选中用 `tab-active`（900），未选中用 `tab`（400，`ink-muted`）。
- 舞台上的菜名每行不超过四个字，按词手动断行（鲜虾蟹籽 / 云吞、柳州 / 螺蛳粉），不要让浏览器在词中间折行。

## 间距与圆角

- 间距用 `space-4` 到 `space-24` 七档。列表行里缩略图和文字隔 `space-14`；成对按钮隔 `space-10`；标签之间 `space-8`。
- 能点的东西都是胶囊（`radius-pill`）：按钮、标签、搜索框、导航。
- 方块图用 `radius-tile`，缩略图用 `radius-thumb` / `radius-thumb-lg`，抽屉顶部用 `radius-sheet`。
- 食物永远是正圆（`radius-plate`）：盘子、地图标记。头像也是圆的。
- 阴影只用在这几处：盘子 `shadow-plate`、悬浮导航和地图浮层 `shadow-float`、地图标记 `shadow-pin`、地图上的抽屉 `shadow-sheet`，以及按钮。其他层次靠颜色和留白，不加卡片投影。
- 按钮带一点厚度，让人一眼知道能按：很轻的上亮下暗渐变（`ink-top` 到 `ink`、`mist-top` 到 `mist`、`paper` 到 `paper-bottom`），加对应的 `shadow-button*`；发布按钮用 `shadow-fab`。不可用和虚线按钮保持扁平。细则见 `Button`。

## 图片：插画与实拍

- 舞台和转盘上的菜一律用 `DishPlate`：圆形取景，加 8px 白色盘沿和投影。用户实拍图和插画走同一个组件。
- 上传时多一步「调整照片」：用户把主菜拖、缩放进圆圈里，默认居中。中餐大多是圆碗圆盘，圆形裁切基本就去掉了背景。自动抠图是可选增强，效果不好时退回圆形裁切。
- 舞台色的取法：只看圆圈里面的像素，按饱和度加权算主色调，再吸附到 9 个 `stage-*` 里最近的一个，另给两个备选。不要直接用平均色：实拍中餐的平均色几乎都是发灰的褐色。
- 转盘上相邻两道菜撞色时，后一道换成它的第二候选。
- 圆圈里饱和度太低、取色不可靠时，用分类默认色：主食 `stage-broth`、小吃 `stage-chili`、饮品 `stage-mango`、甜品 `stage-porcelain`、汤 `stage-bamboo`、火锅 `stage-redoil`、烧烤 `stage-soy`、凉菜和配菜 `stage-matcha`、其他 `stage-bamboo`。
- 上传的人可以在推荐的三个颜色里改选（`StageColorPicker`）；裁切位置和舞台色随菜品一起保存。
- 推荐流里的方块（`DishTile`）直接放原图，`object-fit: cover`，不套盘沿。
- `assets/Dishes` 里的插画只用于空状态、引导和演示，不能冒充用户上传的照片。

## 动效

- 转盘吸附：680ms，`cubic-bezier(0.2, 0.9, 0.25, 1.1)`，略带回弹，像真的转盘停下来。
- 拖动跟手：每拖 1px 转 180 / (π × 430) ≈ 0.133°，也就是约 7.5px 转 1°。拖过 30px（约 4°）松手就换一道，一次只转一格。
- 舞台换色：背景和文字颜色 500ms `ease` 一起过渡。
- 选中态（标签、单选、开关）：160–200ms。
- 按钮按下：整体下移 1px，阴影收小，90ms；松开弹回。
- 登录页转盘 90 秒匀速转一圈；系统开启「减少动态效果」时停住。其他地方不放自动播放的动画。

## 状态

- 选中：导航项用 `mist` 底加 700 字重；单选分类用 `ink` 底 `paper` 字；多选标签用 `tag-selected` 底加 `ink` 描边；单选行用 `mist` 底加 `ink` 实心圆勾。
- 开关：开是 `ink` 轨道、圆钮在右，关是 `handle` 轨道、圆钮在左，旁边一定有文字（见 `Switch`）。
- 未读：7px `ink` 圆点放在行首，读过就去掉。
- 按下：按钮下沉 1px，换成 `-pressed` 阴影。
- 不可用：`disabled-bg` 底、`disabled-fg` 字，没有厚度，同时在附近用 `warn` 文字说明怎样才能用。
- 待接入：`line-strong` 虚线胶囊，写「待接入」。
- 键盘焦点：2px `paper` 内圈加 2px `ink` 外圈的双环，深浅舞台上都看得见。

## 图标

- 用 MingCute 的 Line 一套：24 网格，2px 描边，圆角端点和拐角。它的线条比常见图标库圆润一些，和 900 字重的中文标题放在一起不显得单薄。全部图标在 `assets/Icons`，按用途命名（`search`、`chevron-right`、`heart-on`），用法见 `Icon`。
- 默认一律线性。只有两个切换状态用实心：赞过 `heart-on`（`stage-tomato`）、收藏过 `bookmark-on`。赞是心形，收藏是书签，不混用。
- 常用尺寸：底部导航 22px，顶栏 22–24px，列表行 20–22px，按钮里 18–20px，文字旁 14–16px。20px 以下把描边加粗，实际线宽保持在 1.5–1.6px。
- 图标颜色跟着所在文字：`ink`、`ink-muted`，或舞台文字色；SVG 里写 `currentColor`。
- 缺图标时先在 MingCute Line 里找，加进 `assets/Icons` 并更新那里的对照表；不混用其他图标库，不用 emoji 当图标。

## 无障碍

- 点击区域不小于 `size-touch`（44px）；36px 高的标签把点击区域向外扩到 44px。
- 能滑的地方都有按钮替代：转盘有「换一个」，取景圈有缩放滑条。
- 文字对比不低于 4.5:1，24px 以上的大字不低于 3:1。每个颜色 token 的说明里写了它能用在哪些底色上，照着用。
- 图片：舞台主图的菜名已经写在旁边，图片本身标为装饰；只有单独出现的菜品图要写替代文字。

## 在 Flutter 里落地

- tokens 做成 `ThemeExtension`（颜色、间距、圆角、阴影），舞台色是一个枚举，每个值带着自己的文字色和次按钮色。
- 页面骨架是一个 `StageScaffold`（舞台色、主图、抽屉内容），`NavBar` 放在 `StatefulShellRoute` 外层的 `Stack` 里。
- 转盘、盘子、舞台色选择器分别对应 `Turntable`、`DishPlate`、`StageColorPicker`，规则见各自的组件说明。
- 图标直接用 `assets/Icons` 里的 SVG，按文件名引用，颜色跟着文字；用什么包渲染 SVG 在依赖选型文档里定。
