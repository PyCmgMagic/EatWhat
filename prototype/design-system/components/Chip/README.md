# Chip

胶囊小标签，三种用法：单选分类、多选标签、「待接入」标记。

**调用方提供**：文字、类型、是否选中、点击回调。

**类型**
- 单选分类（菜品分类、商圈）：36px 高；未选中 `mist` 底 `ink` 字，选中 `ink` 底 `paper` 字、600 字重。一组里只能有一个选中。
- 多选标签（口味标签）：36px 高，1.5px 描边；未选中 `paper` 底 `handle` 描边，选中 `tag-selected` 底 `ink` 描边、600 字重。
- 补充入口：1.5px `line-strong` 虚线描边，写「＋ 自己写」「＋ 加标签」。
- 待接入：11px 文字，1px `line-strong` 虚线描边，写「待接入」，跟在没有接口的功能名后面。
- 地图上的商圈：选中 `ink` 底，未选中 `paper` 底加 `shadow-float`。

**规则**
- 标签之间 `space-8`，放不下就换行（分类可以横向滚动）。
- 点击区域扩到 44px。
- 菜品分类和后端枚举一一对应：主食 STAPLE、饮品 DRINK、小吃 SNACK、甜品 DESSERT、汤 SOUP、火锅 HOT_POT、烧烤 GRILL、凉菜 COLD_DISH、配菜 SIDE_DISH、其他 OTHER。

**不要**
- 用舞台色给标签上色。
- 在一个标签里放图标加文字加计数三样东西。
