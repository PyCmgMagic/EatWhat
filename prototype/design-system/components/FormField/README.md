# FormField

大字输入：上面一行 13px 标签，下面是没有边框、只有一条 `handle` 下划线的大号输入框，填进去的内容本身就像标题。

**调用方提供**：标签、值、占位文字、输入类型；价格字段额外带「¥」前缀。

**规格**
- 标签 13px `ink-muted`，和输入框隔 2px。
- 菜名输入 22px 900 `ink`，高 40px，下划线 1.5px `handle`，获得焦点时下划线变 `ink`。
- 价格输入用 `numeral` 字体 22px 800，「¥」前缀同字体同字号，`inputmode="decimal"`。
- 菜名和价格可以并排：菜名占剩余宽度，价格固定约 104px，间距 `space-16`。
- 一组选项用 `fieldset` 加 `legend`（分类、标签），里面放 `Chip`。
- 出错时下划线和说明文字都用 `warn`，说明写在输入框下面：说清楚哪里不对、怎么改。

**不要**
- 用带边框的方框输入框。
- 只用占位文字代替标签。
