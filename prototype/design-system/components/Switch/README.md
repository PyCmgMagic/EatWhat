# Switch

开关：设置里的通知、隐私、个性化推荐，附近筛选里的「只看推荐率 80% 以上」。一行文字在左，开关在右，整行都能点。

**调用方提供**：文字、可选的一行说明、开或关、切换回调。

**规格**
- 轨道 52×32，`radius-pill`，内边距 3px；圆钮 26px，`paper`，带一层很轻的投影 `0 1px 3px rgba(35, 28, 24, 0.28)`。
- 开：轨道用 `ink-top` 到 `ink` 的渐变，圆钮在右。关：轨道 `handle`，圆钮在左。
- 切换 180ms，圆钮和轨道颜色一起变。
- 行高至少 56px；有说明时文字 16px，说明 13px `ink-muted`，开关垂直居中。
- 用 `role="switch"` 加 `aria-checked`，并用 `aria-labelledby` 指向左边的文字。

**规则**
- 开关立即生效，不再配「保存」按钮。
- 还没有接口的开关照样画出来，文字后面跟「待接入」（见 `Chip`），点了不发请求。
- 关掉会影响别人看到的内容时（公开关注列表、公开粉丝列表），说明里写清楚别人会看到什么。

**不要**
- 用舞台色或 `warn` 给开关上色。
- 用开关做需要确认的操作（退出登录、注销账号），那些用按钮。
