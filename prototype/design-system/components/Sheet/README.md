# Sheet

舞台下方的白色抽屉：顶部两角 `radius-sheet`，从舞台底部往上压 32px，所有列表和次要信息都放在里面。

**调用方提供**：内容（分类、方块、列表、表单）。

**规格**
- 底色 `paper`，顶部居中一个 36×4 的把手（`handle`），把手下面 `space-14` 开始放内容。
- 左右内边距 `space-20`，分区之间 `space-14` 到 `space-24`。
- 压在舞台色上时不要阴影；压在地图上时加 `shadow-sheet`。
- 抽屉里不再套卡片：分区靠标题（`section-title`）和留白隔开。

抽屉是页面的一部分，跟着页面一起滚动。临时弹出来做选择的是底部面板，见 `Panel`。

**不要**
- 给抽屉里的每一块加背景和圆角，变回「一堆圆角卡片」。
- 在抽屉里再放一个舞台色区域。
