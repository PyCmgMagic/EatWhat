# Button

所有按钮都是带一点厚度的胶囊：白底页面上主操作用 `ink` 实心，次操作用雾面或描边；舞台上的按钮跟着舞台色走。

**调用方提供**：文字（写清楚会发生什么）、类型、可选图标、是否可用。

**类型**
- 实心（主操作）：`ink-top` 到 `ink` 的竖向渐变、`paper` 字、`shadow-button`，高 `size-button`，文字 `button-label`。一屏最多一个。
- 描边：`paper` 底、`shadow-button-outline`（1.5px `ink` 描边加一道浅底边），用于和实心按钮并排的次操作（导航去店里）。
- 雾面：`mist-top` 到 `mist` 的渐变、`ink` 字、`shadow-button-light`，用于白底上的次操作。
- 虚线：1.5px `line-strong` 虚线边，没有底色和厚度，用于「新建」「自己写」这类补充入口。
- 舞台实心：浅色舞台上就是 ink 实心按钮，文字换成舞台色；深色舞台上用 `paper` 到 `paper-bottom` 的渐变、舞台色文字、`shadow-button-on-stage`。
- 舞台次按钮：`stage-ghost-light` / `stage-ghost-dark` 底加 `shadow-button-ghost`，像一块磨砂玻璃，文字 = 舞台文字色。
- 不可用：`disabled-bg` 底、`disabled-fg` 字，完全扁平，附近用 `warn` 文字说明原因。

**立体感**
- 只有能按的按钮才有厚度：顶部 1px 内高光，底部 2px 内阴影，外面一层贴身的小投影；底色是一道很轻的上亮下暗渐变，上下亮度差不超过 6%。
- 按下时整体下移 1px，阴影换成对应的 `-pressed` 版本，过渡 90ms；松开后弹回。
- 不可用和虚线按钮保持扁平：扁平就等于「现在按不了」或「只是补充入口」。
- 发布按钮用同样的做法，只是投影更深（`shadow-fab`），因为它浮在内容上。

**规则**
- 成对出现时左次右主，等宽，间距 `space-10`。
- 带图标时图标 18–20px，在文字左边，间距 `space-8`。
- 只有图标的按钮至少 44×44，并写 `aria-label`。

**不要**
- 用彩色（`stage-*`）做白底页面上的按钮。
- 加长投影、彩色发光或明显的渐变；厚度要「摸得到但看不出做了效果」。
- 给分类标签、列表行这些非按钮元素加按钮的厚度。
- 写「确定」「提交」这类说不清后果的文字。
