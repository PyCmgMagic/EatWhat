# SearchField

胶囊形搜索框：白底页面上用 `mist` 底，浮在地图上时用 `paper` 底加 `shadow-float`。

**调用方提供**：占位文字（说清楚能搜什么：「搜店名」「搜店名或菜名」）、输入回调、可选的右侧筛选按钮。

**规格**
- 高 48–50px，`radius-pill`，左内边距 16px；20px 搜索图标，和文字隔 `space-10`。
- 文字 15px `ink`，占位文字 `ink-muted`。
- 右侧筛选按钮 42px 圆，`mist` 底，放在胶囊里面。
- 用 `type="search"` 和 `aria-label`。

**不要**
- 写「请输入关键词」这类不说明能搜什么的占位文字。
- 给搜索框加描边。
