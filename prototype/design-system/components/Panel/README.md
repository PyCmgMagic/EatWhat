# Panel

底部面板：压在当前页面上的临时选择和确认，比如地点和饭点、附近筛选、加标签、举报、退出登录的确认、拦截提示。选完就收起，不跳新页面。

**调用方提供**：标题、内容（单选行、标签、开关、文字框）、底部按钮、关闭回调。

**规格**
- 背后一层 `scrim` 盖住整页，点遮罩等于关闭。
- 面板底色 `paper`，顶部两角 `radius-sheet`，顶部居中 36×4 的把手（`handle`）。
- 左右内边距 `space-20`，底部留 32px 再加系统安全区。
- 标题 `section-title`，右边一个 44×44 的关闭按钮（`close` 图标 22px）；需要补一句说明时，标题下面一行 13px `ink-muted`。
- 分组用 13px 600 `ink-muted` 的小标题，组和组之间 18px。单选用 `RadioRow` 的样子（没有缩略图时行高 52–64px），多选用 `Chip`，开关用 `Switch`。
- 底部按钮：一个主按钮，或「重置」（雾面，固定宽）加主按钮。主按钮的文字带上结果，如「看 12 家」。
- 提交后的结果留在面板里：一个对勾、一句「收到了，我们会尽快处理」和「好的」，不弹 toast。
- 出现和收起 240ms，从底部滑入；系统开启减少动态效果时直接显示。

**规则**
- 选了立即生效的（地点和饭点）不放确认按钮；需要一起提交的（筛选、举报）才放。
- 面板高度跟着内容走，最高到屏幕的 85%，超出时面板内部滚动。
- 有破坏性的确认（退出登录）主按钮写动作本身（「退出」），次按钮写「先不退」，不写「确定」「取消」。

**不要**
- 在面板里再开一个面板。
- 用面板装长页面（全部评论、设置），那些是白底页面。
- 用舞台色做面板底色。
