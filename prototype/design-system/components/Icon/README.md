# Icon

线性图标，取自 MingCute 的 Line 一套：24 网格、2px 描边、圆角端点，线条比常见图标库更圆润，和 Noto Sans SC 的粗字放在一起不显得单薄。文件在 `assets/Icons`，按用途命名。

**调用方提供**：图标名（用途名，如 `search`、`chevron-right`）、尺寸、颜色（跟着所在文字）。

**尺寸**
- 底部导航 22px；顶栏和页面右上角 22–24px；列表行和设置行 20–22px；按钮里 18–20px；跟在文字旁边 14–16px。
- 20px 以下把描边加粗，让实际线宽保持在 1.5–1.6px：14px 用 2.6、16px 用 2.4、18px 用 2.13（都是 24 网格里的数值）。20px 以上保持 2。
- 只有图标的按钮，点击区域至少 `size-touch`。

**颜色**
- SVG 里写 `currentColor`，颜色跟着所在文字：`ink`、`ink-muted`，舞台上用舞台文字色。
- 赞过的心形（`heart-on`）用 `stage-tomato`，这是唯一带颜色的图标。

**线性和实心**
- 默认一律线性。只有两个切换状态用实心：赞过 `heart-on`、收藏过 `bookmark-on`。
- 赞是心形，收藏是书签，两者不要混用。

**无障碍**
- 图标旁边有文字时标为装饰（`aria-hidden`）；只有图标时给按钮写 `aria-label`，说清楚动作（「返回」「分享」「更多」）。

**不要**
- 混用其他图标库，或者用实心图标表示普通状态。
- 用颜色表示选中（导航、分类选中靠底色和字重）。
- 用 emoji 代替图标。
- 自己改图标的路径；缺图标时先在 MingCute Line 里找同一套的，加进 `assets/Icons` 并写进那个分组的说明。
