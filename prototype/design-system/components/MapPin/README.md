# MapPin

附近页地图上的店铺标记：一个白色小圆盘，里面放这家店招牌菜的圆形图；选中的那家放大，外圈加一道它的舞台色。

**调用方提供**：招牌菜图片、店名、坐标、是否选中、舞台色。

**规格**
- 普通标记：44px 白色圆，里面 38px 圆图，`shadow-pin`。
- 选中标记：72px 白色圆，里面 64px 圆图，外圈 4px 舞台色，阴影加深；下面跟一个 `ink` 底 `paper` 字的店名小胶囊。
- 我的位置：15px `map-me` 圆点、3px 白边，外面 48px 的 16% 光晕。
- 商圈范围：1.5px `ink` 虚线圆角框，填充 24% 的当前舞台色。
- 每个标记都是按钮，带店名做 `aria-label`。

**不要**
- 用通用的水滴形图钉。
- 在地图上同时放大两个标记。
