# StageColorPicker

「调整照片」页底部的舞台色选择：从照片里推荐三个舞台色，默认选第一个，下面实时预览这道菜在首页的样子。

**调用方提供**：三个候选（`stage-*` 名字，按推荐顺序）、当前选择、菜名、裁好的圆图、选择回调。

**规格**
- 放在 `crop-panel` 底的面板里，标题「舞台颜色」15px 600 `paper`，说明「从照片里推荐」12px，70% 不透明。
- 三个 36px 色圆，下面写颜色名（11px）；选中项外面加 3px `crop-panel` 间隔环和 2px 白环。一组用 `role="radiogroup"`。
- 预览卡：84px 高，`radius-tile`，底色 = 当前选择，文字按这个色的深浅用 `ink` 或 `paper`；右上角放一个 100px 的 `DishPlate`（4px 盘沿）。切换时底色 300ms 过渡。
- 候选的来源：圆圈内按饱和度加权求主色调，吸附到最近的三个 `stage-*`；照片太灰时把分类默认色放在第一位。

**不要**
- 给一个任意取色的调色盘，舞台色只能从 9 个里选。
- 把预览做成静态图，它必须跟着选择变。
