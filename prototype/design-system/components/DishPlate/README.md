# DishPlate

把一道菜显示成一个盘子：圆形取景的照片，外面一圈白色盘沿加投影；实拍图和插画都走它。

**调用方提供**：图片、裁切位置（圆心和缩放，来自「调整照片」那一步）、尺寸、是否带投影。

**尺寸**
- 舞台主图：外框 `size-plate`（320px），盘沿 8px，`shadow-plate`。
- 转盘预览、色卡预览：100–200px，盘沿 4–6px。
- 列表缩略：48–64px，不加盘沿，改用 `radius-thumb` 方圆角（见 `ListRow`）。

**规则**
- 永远是正圆（`radius-plate`），图片 `object-fit: cover`，按保存的圆心和缩放来裁。
- 插画本身已经画了碗盘，直接放，不再加盘沿。
- 照片太小时宁可把盘子缩小，也不要放大到糊。

**不要**
- 用方形或圆角矩形来放舞台主图。
- 给盘子加彩色描边，或者在盘子上叠文字。
