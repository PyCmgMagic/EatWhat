# RadioRow

整行可点的单选项，用在发布第 1 步「在哪家吃的？」：选中的那行铺一层 `mist`，右边圆圈变成 `ink` 实心加勾。

**调用方提供**：缩略图、标题、距离、商圈、是否选中、选中回调。

**规格**
- 行高 68px，`radius-tile` 圆角的选中底，左右内边距 10–12px。
- 52px 缩略图（`radius-thumb`），标题 `row-title`，第二行 `distance` 加 `meta`。
- 右侧 24px 圆：未选中 2px `line-strong` 描边，选中 `ink` 实心加 14px 白勾。
- 一组用 `role="radiogroup"`，每行 `role="radio"` 加 `aria-checked`。
- 选中态 200ms 过渡。
- 列表下面放一个「＋ 没找到？新建一家店」虚线按钮；底部主按钮把选中项写进文字：「下一步：给袁记云饺加菜」。

**不要**
- 只靠背景色区分选中，右边的圆圈必须一起变。
