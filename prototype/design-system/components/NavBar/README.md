# NavBar

悬浮在三个主页面底部的导航：左边是「发现 / 附近 / 我的」三个标签组成的胶囊，右边紧挨着一个黑色圆形发布按钮。

**调用方提供**：当前是哪个标签；三个标签的去向；发布按钮的去向（发布第 1 步：选店）。

**规格**
- 整体高 `size-nav`（60px），距屏幕左右 `space-16`、距底部 `space-24`（再加系统安全区）。
- 标签胶囊：`paper` 94% 不透明加背景模糊，`shadow-float`，内边距 5px，三个标签等分。
- 标签：22px 线性图标在上，`nav-label` 文字在下。当前项用 `mist` 胶囊底、`ink` 文字、700 字重；其他项 `ink-muted`、500。
- 发布按钮：60px 圆，`ink` 底，26px「＋」，`shadow-fab`，`aria-label="发布一道菜"`。
- 消息不在导航里，入口是发现页右上角的铃铛。

**不要**
- 把「＋」放在三个标签中间，四个位置没有正中间。
- 换成实心图标或彩色图标来表示选中。
- 在详情页、发布流程里显示导航。
