# Tabs

用字重区分选中的文字分类：选中项 900 字重、17px，其他项 400 字重、15px、`ink-muted`，没有下划线也没有底色。

**调用方提供**：分类名、可选计数、当前项。

**规格**
- 选中 `tab-active`（`ink`），未选中 `tab`（`ink-muted`），按基线对齐，间距 20–22px。
- 计数用 `count`（Bricolage Grotesque），跟在文字后面 `space-4`。
- 行高 32px，点击区域上下扩到 44px。
- 放不下时横向滚动，不换行。
- 待接入的分类照样列出，后面跟「待接入」小标（见 `Chip`）。

**不要**
- 加下划线、色块或彩色文字表示选中。
- 超过 6 个分类；更多分类放进筛选。
