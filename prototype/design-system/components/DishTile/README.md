# DishTile

推荐流和「我的」里的菜品方块：上面一张直接用原图的圆角方图，菜名和店名写在图外面。

**调用方提供**：原图、菜名、店名或收藏数、去向（菜品详情）。

**规格**
- 两列网格，列间距 `space-14`，行间距 18px；图高 150px，`radius-tile`，`object-fit: cover`。
- 图下 `space-8` 放菜名 `tile-title`，再下面店名 `meta`（`ink-muted`）；「我的」里改为右侧显示收藏数 `count`。
- 整块是一个链接。
- 图片还没加载出来时底色用 `mist`。

**不要**
- 把文字压在图上，或者给方块加底色、边框、阴影。
- 给方图套盘沿：盘沿只属于舞台和转盘。
