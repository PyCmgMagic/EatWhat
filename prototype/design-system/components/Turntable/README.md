# Turntable

首页舞台里的转盘：几道菜摆在一张大圆桌的边上，左右拖动或点「换一个」就转到下一道，舞台颜色跟着换。

**调用方提供**：一组菜（每道带照片、裁切位置、舞台色）、当前序号、换菜回调。

**规格**
- 圆心在屏幕右下方之外，菜离圆心 `size-turntable-radius`（430px），相邻两道相隔 55°。屏幕上只看到当前这道和左下角露出的上一道。
- 桌面用 `table-light` / `table-dark`，外面一圈 1.5px 细边用 `table-ring-light` / `table-ring-dark`。
- 拖动跟手：每 7.5px 转 1°；松手时拖过约 30px 就换一道，一次只转一格；吸附动画 680ms `cubic-bezier(0.2, 0.9, 0.25, 1.1)`。
- 离开当前位置的菜缩到 0.85 倍；实拍照片保持正向不跟着桌子转（插画可以跟着转）。
- 至少 5 道菜才能无缝循环；绕到看不见的位置时把菜隐藏，避免从前面扫过去。
- 舞台左栏下面放一排小圆点，当前那道拉长成 16px。

**要做**
- 永远保留「换一个」按钮，作为不能滑动时的替代。
- 只在舞台区域内响应左右拖动，上下滑动交给页面滚动。

**不要**
- 一次转好几格，或者自动轮播。
- 让两道相邻的菜用同一个舞台色（撞色时顺延到第二候选）。
