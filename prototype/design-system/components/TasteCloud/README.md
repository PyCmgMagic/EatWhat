# TasteCloud

「大家怎么说」：把一道菜或一家店的口味标签排成一行字，打这个标签的人越多，字越大越重。

**调用方提供**：标签列表（名字、次数，对应接口的 `FoodSystemTagVO.count`）、点击回调（按这个标签筛选），可选「＋ 加标签」入口。

**规格**
- 按次数从高到低排，最多 6 个。字号分四档：最高 28px/900，其次 21–22px/700，再次 17–19px/600，其余 15–16px/500。
- 前两档用 `ink`，后两档用 `ink-soft`（舞台上）或 `ink-muted`（白底上）。
- 次数用 `count`，跟在字后面，按基线对齐。
- 每个词是一个按钮，最小点击高度 44px，词之间横向 16px。
- 最后可以跟一个「＋ 加标签」虚线胶囊（见 `Chip`）。

**不要**
- 给词加底色或边框做成一排胶囊。
- 用颜色深浅代替字号表示多少。
