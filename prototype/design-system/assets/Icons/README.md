界面里用到的全部图标，取自 MingCute 的 Line 一套（Apache-2.0），另有两个实心：`heart-on`（赞过）和 `bookmark-on`（收藏过）。24×24，2px 描边，颜色写 `currentColor`，跟着所在文字变色。文件按用途命名，不按图标库的名字；对应关系如下，缺图标时从同一套里补，并更新这张表。

| 文件 | 用途 | MingCute |

| `discover` `nearby` `me` | 底部导航 | compass、location、user-3 |
| `add` | 发布、加一张照片 | add |
| `search` `filter` `sort` | 搜索、筛选、排序 | search、settings-6、sort-descending |
| `bell` `notify-off` `moon` | 消息、系统通知关着、免打扰时段 | notification、notification-off、moon |
| `back` `close` `chevron-right` `chevron-down` `more` | 返回、关闭、进入、展开、更多 | left、close、right、down、more-1 |
| `check` `check-circle` `add-circle` `close-circle` | 勾选、完成、添加、清空输入 | check、check-circle、add-circle、close-circle |
| `shuffle` | 换一个 | refresh-2 |
| `share` `link` `copy` `external` | 分享、复制链接、复制、跳到外部页面 | share-forward、link、copy-2、external-link |
